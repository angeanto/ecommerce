# Session 6 - Data Governance and Scaling Analytics

## Position in the Program

Participants learn how trusted analytics scales through ownership, definitions, quality checks, documentation, access rules, and dashboard lifecycle management.

## Core Questions

- Who owns this metric and its definition?
- How do we know the data is reliable?
- When should a dashboard or model be changed, retired, or promoted?

## Session Goals

- Understand practical governance for analytics teams.
- Create metric definitions with owners and quality rules.
- Use dbt tests and documentation as governance mechanisms.
- Design a dashboard lifecycle that avoids clutter and confusion.
