# Session 1 - Modern Data Analyst: From Request Taker to Business Partner

## Position in the Program

Participants learn how to treat analytics as a business craft: framing requests, clarifying decisions, negotiating scope, and owning the path from question to action.

## Core Questions

- What decision is this work supposed to influence?
- Who owns the action after the analysis is delivered?
- What is the smallest reliable output that can move the work forward?

## Session Goals

- Separate requests, questions, decisions, and outputs.
- Practice intake conversations that expose context, constraints, and trade-offs.
- Use prioritization language that protects quality without sounding defensive.
- Recognize analyst behaviors that create trust before any dashboard is built.

1. Framing and business relevance.
2. Core teaching concepts.
3. E-commerce database walkthrough or work sample.
4. Participant reflection and debrief.
5. Homework setup.

## Expected Participant Output

By the end of this session, participants should have a concrete artifact they can reuse at work or in their portfolio, not only notes from the lesson.
