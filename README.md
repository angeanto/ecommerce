# Data Career Accelerator

Data Career Accelerator is an eight-session virtual course and digital product for analysts who want to move beyond isolated tools and become stronger business-facing data professionals.

The course uses one continuous e-commerce analytics case study across SQL, data modeling, dbt, BI, stakeholder communication, governance, AI-assisted analytics, and career positioning. Each session folder contains presentation notes, examples, self-assessment material, and participant take-home assets.

## How to Use This Repo

1. Start with `ecommerce_db/README.md` to install and run the case study database and dbt project.
2. Use each session folder in order. The examples build on the same schema and business scenario.
3. Copy self-assessment questions into Google Forms when preparing the cohort experience.
4. Use `take-home-assets.md` as the participant assignment and review rubric for each session.

## Product Recommendations

- Package the course as live sessions plus a self-paced workspace. The database and dbt project are the anchor that makes every concept practical.
- Add a capstone at the end: participants submit a KPI tree, dbt model explanation, dashboard readout, AI verification artifact, and career positioning package.
- Maintain a facilitator version and a participant version of each artifact if the course scales to multiple cohorts.
- Add short Loom-style walkthroughs for setup, dbt lineage, and the final portfolio package.
- Track participant confidence using the self-assessments before Session 1 and after Session 8 to show measurable transformation.
