# Session 7 - Analytics in the AI Era

## Position in the Program

Participants learn how to use AI as an analytics accelerator while protecting judgment, context, verification, privacy, and business accountability.

## Core Questions

- Which parts of the workflow can AI accelerate safely?
- What context does the model need to produce useful work?
- How will I verify the result before anyone uses it?

## Session Goals

- Identify high-value AI use cases across analytics work.
- Write context-rich prompts for SQL, documentation, and communication.
- Detect AI failure modes such as wrong grain, missing filters, and invented definitions.
- Build a verification habit that keeps humans accountable.

## Files in This Folder

- `presentation.md` - Version-controlled slide outline and speaker notes for the Canva deck.
- `examples.md` - E-commerce database examples, code, and facilitation notes.
- `self-assessment.md` - Google Forms-ready self-assessment blueprint.

## Live Session Flow

1. Framing and business relevance.
2. Core teaching concepts.
3. E-commerce database walkthrough or work sample.
4. Participant reflection and debrief.
5. Homework setup.

## Expected Participant Output

By the end of this session, participants should have a concrete artifact they can reuse at work or in their portfolio, not only notes from the lesson.
