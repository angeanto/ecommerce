# Self-Assessment - Session 3 - Data Engineering for Analysts: Pipelines, dbt, and Git

## Google Forms Setup

Form title: Data Career Accelerator - Self-Assessment - Session 3

Description: Use this assessment to reflect on your readiness after Session 3. The goal is not to score perfectly. The goal is to identify which behaviors and skills need deliberate practice.

Scale:

- 1 - Rarely true
- 2 - Sometimes true
- 3 - Mostly true
- 4 - Strongly true
- 5 - Consistently true

## Section - Pipeline Thinking
Use a linear scale from 1 to 5.

- I can explain why raw data should not feed dashboards directly.
- I can describe what belongs in staging models.
- I can describe what belongs in intermediate models.
- I can describe what belongs in reporting models.

## Section - dbt Practice
Use a linear scale from 1 to 5.

- I can read a dbt model and identify its dependencies.
- I can run selected dbt models locally.
- I can add a useful schema test.
- I can write a clear model description.

## Section - Git Workflow
Use a linear scale from 1 to 5.

- I work on a branch instead of main.
- I make commits that describe the analytical change.
- I can explain my changes in a pull request.
- I avoid mixing unrelated edits in one commit.

## Section - Production Quality
Use a linear scale from 1 to 5.

- I think about how a model can fail.
- I validate counts before and after transformations.
- I know where to document assumptions.
- I treat analytics code as shared product code.


## Scenario Check

A stakeholder wants a new dashboard metric tomorrow. The query works in a notebook but has no tests or documentation. What minimum production path do you propose?

Suggested response format:

- What is the real business problem?
- What information do you need next?
- What action would you recommend?
- What risk or assumption should be communicated?

## Reflection

- What is one skill from this session that already feels strong?
- What is one behavior you will practice this week?
- What evidence would show that you improved?
