# Session 3 - Data Engineering for Analysts: Pipelines, dbt, and Git

## Position in the Program

Participants learn how analyst work becomes reliable production work through layered pipelines, dbt models, tests, documentation, and Git collaboration.

## Core Questions

- Where does raw data become trusted analytics logic?
- Which tests prevent bad numbers from reaching users?
- How does Git make analytical work reviewable and recoverable?

## Session Goals

- Understand source, staging, intermediate, and reporting layers.
- Read and extend a dbt project structure.
- Add tests and documentation for core metrics.
- Practice a basic Git branch, commit, and pull request workflow.

## Files in This Folder

- `presentation.md` - Version-controlled slide outline and speaker notes for the Canva deck.
- `examples.md` - E-commerce database examples, code, and facilitation notes.
- `self-assessment.md` - Google Forms-ready self-assessment blueprint.
- `take-home-assets.md` - Homework, templates, and participant deliverables.

## Live Session Flow

1. Framing and business relevance.
2. Core teaching concepts.
3. E-commerce database walkthrough or work sample.
4. Participant reflection and debrief.
5. Homework setup.

## Expected Participant Output

By the end of this session, participants should have a concrete artifact they can reuse at work or in their portfolio, not only notes from the lesson.
