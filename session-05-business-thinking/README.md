# Session 5 - Business Thinking: Domains, KPIs, Stakeholders, and Strategy

## Position in the Program

Participants learn how to connect data work to strategy, domain dynamics, KPI trees, stakeholder incentives, and trade-off-aware recommendations.

## Core Questions

- Which business lever does this metric represent?
- Which stakeholder incentives shape the request?
- What trade-off is hidden behind the recommendation?

## Session Goals

- Build KPI trees from strategic objectives.
- Map stakeholder incentives and possible metric conflicts.
- Translate domain context into better analysis choices.
- Write recommendations that show business judgment.

## Files in This Folder

- `presentation.md` - Version-controlled slide outline and speaker notes for the Canva deck.
- `examples.md` - E-commerce database examples, code, and facilitation notes.
- `self-assessment.md` - Google Forms-ready self-assessment blueprint.

## Live Session Flow

1. Framing and business relevance.
2. Core teaching concepts.
3. E-commerce database walkthrough or work sample.
4. Participant reflection and debrief.
5. Homework setup.

## Expected Participant Output

By the end of this session, participants should have a concrete artifact they can reuse at work or in their portfolio, not only notes from the lesson.
