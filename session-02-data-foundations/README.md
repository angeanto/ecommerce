# Session 2 - Databases, Warehousing, SQL, and Data Modeling Foundations

## Position in the Program

Participants build the base technical vocabulary needed to understand databases, warehouses, SQL, grains, joins, dimensional modeling, and analytics-ready tables.

## Core Questions

- What is the grain of this table or result?
- Which relationships can multiply rows?
- What model structure makes a metric easy and safe to use?

## Session Goals

- Understand the difference between operational schemas and analytical models.
- Practice SQL patterns that analysts use repeatedly.
- Identify facts, dimensions, grains, and common join traps.
- Map the e-commerce schema into a simple star model.

1. Framing and business relevance.
2. Core teaching concepts.
3. E-commerce database walkthrough or work sample.
4. Participant reflection and debrief.
5. Homework setup.

By the end of this session, participants should have a concrete artifact they can reuse at work or in their portfolio, not only notes from the lesson.
