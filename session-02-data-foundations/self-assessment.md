# Self-Assessment - Session 2 - Databases, Warehousing, SQL, and Data Modeling Foundations

## Google Forms Setup

Form title: Data Career Accelerator - Self-Assessment - Session 2

Description: Use this assessment to reflect on your readiness after Session 2. The goal is not to score perfectly. The goal is to identify which behaviors and skills need deliberate practice.

Scale:

- 1 - Rarely true
- 2 - Sometimes true
- 3 - Mostly true
- 4 - Strongly true
- 5 - Consistently true

## Section - Database Concepts
Use a linear scale from 1 to 5.

- I can explain primary keys and foreign keys.
- I can identify one-to-many and many-to-many relationships.
- I know when a table is operational rather than analytical.
- I can read a schema and predict useful joins.

## Section - SQL Reliability
Use a linear scale from 1 to 5.

- I define the grain before joining tables.
- I use CTEs to make logic readable.
- I check row counts after joins.
- I can use aggregate filters and window functions appropriately.

## Section - Modeling
Use a linear scale from 1 to 5.

- I can separate facts from dimensions.
- I can design a simple revenue mart.
- I understand why dimensions need stable keys.
- I can spot metrics that need clear status rules.

## Section - Business Translation
Use a linear scale from 1 to 5.

- I can explain a technical model in business terms.
- I can describe how a model supports a dashboard.
- I can document assumptions in plain language.
- I can identify where definitions may create stakeholder conflict.


## Scenario Check

A revenue dashboard joins orders to line items and then sums order total. The number is too high. What happened, and how would you fix the model?

Suggested response format:

- What is the real business problem?
- What information do you need next?
- What action would you recommend?
- What risk or assumption should be communicated?

## Reflection

- What is one skill from this session that already feels strong?
- What is one behavior you will practice this week?
- What evidence would show that you improved?
